# Interactive To-Do List Challenge

An interactive, responsive web application built as part of the **eHealth Africa Academy** JavaScript curriculum. This project demonstrates DOM manipulation, event handling, dynamic styling, and basic state toggling in modern JavaScript.

---

## 📋 Features

* **Interactive Task State:** Toggle tasks between incomplete (default gray styling) and completed (green background with line-through effect).
* **DOM Event Handling:** Uses event listeners attached to individual DOM nodes for seamless interactivity.
* **Clean Code Structure:** Modular directory layout separating HTML structure, CSS styling, and JavaScript logic.
